Dr. Mario Producer

Captures a Dr. Mario feed and streams it to the server for broadcast. This page works the same way whether you're broadcasting solo or racing in Speed mode -- Speed attachment is configured entirely by the race admin elsewhere, nothing to set up here. See CLAUDE.md for the rest of the roadmap.

1. Quick seed

Single-player only: the bottle, next-pill preview, and TOP/SCORE/LEVEL/ SPEED/VIRUS panels are each captured and calibrated independently below (step 2) -- different remote captures can crop or letterbox the screen inconsistently (extra overscan rows, a template that crops tighter at the bottom, etc.), so no single whole-screen rectangle can reliably locate all of them at once. This step just gives every region below a reasonable starting value in one click, which you can then fix up individually where it's actually off.

Green box: the calibrated whole screen (used only to detect the title screen, and as this quick-seed's source). Yellow box: the bottle/field region's current calibration (see step 2) -- it should hug the cyan walls snugly; if it doesn't once you've quick-seeded, fix it directly in its own box below rather than re-clicking here.

2. Fine-tune each region (single-player only)

Each box shows exactly what that region currently captures (post-margin for the bottle, at its real working size) -- adjust a region's own X/Y/W/H directly if it looks wrong; this never affects any other region. Saved automatically.
